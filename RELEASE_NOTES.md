# Release Checklist

Short checklist for the release drill runbook. Work through each item before merging.

- [ ] Confirm the default branch is up to date and the target version number is agreed
- [ ] Cut the feature branch (e.g. `drill/notes`) from the default branch before making changes
- [ ] Open a pull request with a clear title and description, and request at least one reviewer
- [ ] Leave at least one code review comment on the change and submit it as a plain comment review (not an approval) before merging
- [ ] Request Copilot's automated code review where available, and record the outcome
- [ ] Merge the pull request and verify the commit SHA landed on the default branch
- [ ] Check GitHub notifications for any follow-ups related to the release drill
